# S2 Competitive Handoff 格式定義

用途：S2 完成後產出，交給 S3（同業篩選參考）與 S6（論點/護城河）。**只填以下結構，不寫散文段落。**

字數預算：與 S1、S3 合計 800-1,200 字（Standard 模式）。

```text
S2 COMPETITIVE HANDOFF

1. Main Competitors（主要競爭對手）
- 競爭者 A：定位／規模
- 競爭者 B：定位／規模

2. Competitive Advantages / Weaknesses（本公司優劣勢）
- 優勢：...
- 劣勢：...

3. Business Model Differences（商業模式差異）
- ...

4. Market Share（市佔率，若有數據）
- 本公司：[數字] [COMP-x]
- 主要對手：[數字] [COMP-x]

5. Moat Assessment（護城河快速評估）
逐項打分 高/中/低，附一句依據：
- 定價能力：
- 轉換成本：
- 規模優勢：
- 品牌：
- 專利／技術門檻：
- 通路／生態系：

6. Source Notes
- [COMP-1] 來源, 日期, 引用內容。

7. What Next Stage Should Use（S3／S6 應該接手的重點）
- ...
```

## 品質規則
- 「Moat Assessment」是機械式評分，不是主觀感想——每一項都要附一句可查證的依據（例如「轉換成本：中，客戶更換供應商需重新驗證製程，平均耗時 6-12 個月 [COMP-3]」），禁止只寫「高／中／低」不附理由。
- 市佔率數字若無法從 FinMind/finlab/官方申報取得，可用產業研究報告估計值，但必須標註「估計值，來源：X」。
