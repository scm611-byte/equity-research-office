# S6 Thesis / Risk Handoff 格式定義

用途：S6 完成後產出，是 S7 最終報告「投資論點」章節的主要輸入，且必須建立在 S1～S5 之上，不可獨立生成。**只填以下結構，不寫散文段落。**

字數預算：與 S4、S5 合計 1,000-1,500 字（Standard 模式）。

```text
S6 THESIS / RISK HANDOFF

1. Core Thesis（核心論點，需引用具體是哪個模組支持）
- ...（例如：「產能利用率持續攀升 [FIN-3]，加上同業定價權評分最高 [COMP-4]，支持營收成長動能延續」）

2. Catalysts（催化劑）
- ...

3. Risks（風險）
- ...

4. What Would Change the View（什麼情況會改變看法）
- ...

5. Preliminary Rating（初步評等，尚未經跨模組交叉檢驗）
- BUY／HOLD／SELL：
- 依據（僅根據本模組＋估值模組）：

6. 自評：跨模組矛盾檢查
逐項檢查，勾選是／否，若是則說明：
- 是否與 S1 市場結論方向相反？
- 是否與 S2 護城河評分矛盾（例如樂觀論點但護城河評分偏低）？
- 是否有同一數字在 S3/S4/S5 出現不同版本？
（有任一項為「是」，交給 Evidence Curator 做正式衝突偵測與裁決，不在本階段自行了斷）

7. Source Notes
- [THESIS-1] 來源, 日期, 引用內容。

8. What S7 Should Use（S7 應該接手的重點）
- ...
```

## 品質規則
- Core Thesis 每一句關鍵論點都要有 `[來源代號]` 引用回 S1～S5 的具體項目，不接受「整體看好」這種沒有 traceable 依據的寫法。
- Preliminary Rating 是「未經跨模組交叉檢驗」的初判，S7 最終評等可能不同——差異與理由由 Evidence Curator／S7 記錄，呼應統籌邏輯裡「結論影響追蹤」的要求。
